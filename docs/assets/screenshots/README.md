# Screenshots

Lege hier deine eigenen Bilder ab (kein offizielles Minecraft-/Mojang-Material) und
trage die Dateinamen in `src/data/content.js` ein.

Empfohlenes Format: WebP, komprimiert, sinnvolle Kantenlänge (z. B. max. 1600px breit).

Erwartete Dateien, sobald du sie hast:

- `hero.webp` (oder `hero.mp4`) — Hero-Hintergrund, eingetragen unter `content.hero`
- `bauwerk-1.webp`, `bauwerk-2.webp`, `bauwerk-3.webp` — Galerie-Bilder, eingetragen unter `content.builds[].image`
- `og-image.webp` (ca. 1200×630px) — Vorschaubild für Open-Graph/Twitter-Cards, referenziert in `index.html`

Ohne diese Dateien zeigt die Seite automatisch passende Platzhalter — nichts ist kaputt.
